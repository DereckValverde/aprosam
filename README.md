# TCU APROSAM

**Sistema de Gestión Administrativa de APROSAM**

## Descripción

Este proyecto se desarrolla como parte del Trabajo Comunal Universitario (TCU) y tiene como institución beneficiaria a la Asociación para la Promoción de la Salud Mental (APROSAM).

El sistema tiene como objetivo apoyar la gestión administrativa de la institución mediante los siguientes módulos:

## Módulos principales

- **Creación de horarios:** permite generar los horarios mensuales de las colaboradoras, facilitando la organización y distribución del personal para conocer quiénes estarán trabajando cada día del mes.

- **Gestión de inventario:** permite llevar un control mensual de las existencias de alimentos, facilitando la identificación de los productos disponibles y de aquellos que deben solicitarse para cubrir las necesidades de la institución.

- **Control de medicamentos:** permite llevar un registro y control de los medicamentos de las personas con discapacidad que residen en la institución, facilitando su seguimiento por parte de las colaboradoras encargadas de su atención.

## Tecnologías

- PHP
- HTML, CSS y JavaScript
- SQLite
- PHP Desktop

## Instrucciones de ejecución

Este proyecto está diseñado para ejecutarse mediante [PHP Desktop](https://github.com/cztomczak/phpdesktop).

1. Descargue y descomprima PHP Desktop.
2. Descargue y descomprima este proyecto.
3. Abra la carpeta de PHP Desktop y localice la carpeta `www`.
4. Sustituya el contenido de `www` por los archivos y carpetas de este proyecto.
5. Ejecute el archivo `.exe` de PHP Desktop para iniciar el sistema.
